# Polina's Birthday Web

Локальный одностраничный сайт-подарок на React + Vite. Все личные подписи и описания отделены от компонентов и находятся в `src/data/`.

## Запуск

```bash
npm install
npm run dev
```

Откройте локальный URL, который покажет Vite (обычно `http://localhost:5173`). Для production-сборки: `npm run build`; результат попадёт в `dist/`.

## Где менять содержимое

- `src/data/content.js` — имя, текст на обложке, письмо и подпись к фото письма.
- `src/data/timeline.js` — периоды дружбы, фото, подписи и тексты глав.
- `src/data/gallery.js` — Hall of Fame.
- `src/data/memes.js` — карточки Meme Museum.
- `src/data/seals.js` — изображения и подписи к тюленям.
- `src/data/reasons.js` — 20 причин (пустые строки для заполнения).
- `src/data/music.js` — названия и пути трёх музыкальных файлов.

Текущие фото, мемы и тюлени в данных ссылаются на уже находящиеся в `public/images/` файлы. Для добавления нового фото положите его в папку нужного раздела, затем добавьте его точное имя файла в соответствующий JS-файл. Если путь не найден, сайт покажет аккуратный слот с именем ожидаемого файла вместо сломанной картинки. Для детских снимков предусмотрены пустые слоты `childhood-01.jpg` и `childhood-02.jpg` в `public/images/childhood/`.

Музыка уже настроена на три найденных MP3 в `public/music/`. Замените `title` и `file` в `src/data/music.js`, если захотите изменить подпись или файл. Автовоспроизведение отключено.
